## B. 実行層の開発（gmo-fx-executor）
- 構成: Cloud Scheduler（5分ごと）→ Cloud Functions（Python）、Firestore（状態・記録・排他）、Secret Manager（API キー）、trading-app-v2 に監視ページ。
- 仕様: `research/executor/gmo-fx-executor-spec.md`（新リポジトリ作成後に移す）
- GMO API で確認済みの事実（2026-09-30、公式ドキュメント・公開API）:
  - IP 制限は任意（会員ページで有効化した場合のみ）
  - 制限は GET 1秒6回・POST 1秒1回
  - API の最小注文数量は4通貨とも **100通貨**、刻み1通貨
  - 逆指値（STOP）・IFD・IFO・注文変更がある
  - 注文ごとの変更回数に上限がある（ERR-5206。具体的な回数は記載なし → 上限に達したら取り消して置き直す設計にする）
  - BID・ASK の5分足が2023年11月以降取得できる（公開 KLine）
