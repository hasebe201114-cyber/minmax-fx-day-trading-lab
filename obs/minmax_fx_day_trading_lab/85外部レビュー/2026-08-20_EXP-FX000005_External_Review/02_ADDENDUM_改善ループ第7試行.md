## 第7試行に固有の所見

### ① 「最大連続損失が初めて K3m 基準を達成」は、大部分がサンプルサイズ効果

第7試行のコミットメッセージは「最大連続損失が初めて K3m 基準を達成」としているが、
Validation のトレード数は 104 → **89 件**に減っている。トレード数が減れば、
エッジが変わらなくても最大連敗は短くなる。

| | 第6試行 Validation | 第7試行 Validation |
|---|---|---|
| n | 104 | 89 |
| 勝率 | 57.7% | 60.7% |
| 観測 最大連敗 | 6（FAIL） | **5（PASS）** |
| **i.i.d. 帰無仮説の期待値** | 4.96 | **4.41** |
| **観測値のパーセンタイル** | 0.72 | **0.60** |

観測値は 6 → 5 と 1 減ったが、帰無分布の期待値も 4.96 → 4.41 と下がっており、
**パーセンタイルは 0.72 → 0.60 とほとんど動いていない**。
つまり「ランダムな系列に対してどれだけ良いか」で見ると、実質的な改善はほぼ無い。
K3m を絶対件数で判定している限り、この種の見かけの改善は今後も繰り返し発生する（→ T-08）。

**なお Train の最大連敗は 6 → 8 に悪化しており（パーセンタイル 0.89）、K3m は依然 FAIL。**

### ② 「Test 7/10」の内訳 — FAIL 3 項目はすべて構造的に達成不能な項目

3期間の FAIL 項目を並べると、**全期間で共通して落ちているのは以下の 3 つだけ**である。

| 期間 | 達成 | FAIL 項目 |
|---|---|---|
| Train | 5/10 | max_dd_monthly / max_consecutive_losses / **payoff_ratio** / **min_n_trades_effective** / **permutation_p** |
| Validation | 5/10 | max_dd_monthly / **payoff_ratio** / spread_cost_multiplier / **min_n_trades_effective** / **permutation_p** |
| Test | **7/10** | **payoff_ratio** / **min_n_trades_effective** / **permutation_p** |

この 3 項目は、レビュー本体が「構造的に達成不能」と指摘したものと**完全に一致する**。

- `payoff_ratio`（K4m ≥1.5）: 出口が「段階利確＋建値」（F3）である限り、勝ちの平均は 1.3R 前後が上限（§1-1）
- `min_n_trades_effective`（≥300）: 4通貨では名目 1,027 件が必要で、戦略コンセプトと両立しない（§2-3）
- `permutation_p`（<0.05）: 4通貨構成では全勝ケースでも p=0.3158（F2）

つまり **「Test 7/10」は「達成可能な 7 項目をすべて達成した」という意味**であり、
その解釈自体は第7試行にとって有利な事実である。しかし同時に、
**残る 3 項目こそが「エッジが本物であること」を示すための項目**（統計的有意性・サンプル数・
リスクリワード）であり、そこは 1 つも動いていない。

達成数スコアではこの構造が見えない。必須ゲートと参考指標の分離（T-11）が必要な理由がここにある。

### ③ Test が 14 回目の参照になった — T-05 の緊急度が上がった

レビュー本体 §3-1 の時点で Test は 13 回参照されていた。第7試行で 14 回目。
「Test 7/10」という数字は、14 回の選択を経た後のものである。

**T-05（Test 凍結宣言）を、他のどの作業よりも先に実施すること。**
第8試行に進む前に宣言しないと、汚染はさらに進む。

### ④ 第7試行の設計自体は評価できる

「カレンダーの固定窓」を「複数通貨が同一 H1 バーで同時にブレイクしたら抑制」へ置き換えた設計は、
**新規の恣意的閾値を導入していない**（既存の検出閾値 `N_BREAKOUT=3.5` を再利用している）点で良い。
また設計 v1 が動機の原点だった 2025-06-13 のクラスタを検出できないことを**自ら発見・訂正**した記録も、
レビュー本体 §3-7 で評価した実践の延長にある。

ただし、この設計変更もまた**改善ループの 7 回目の試行**であり、多重検定の回数として
数える対象である（T-18）。
