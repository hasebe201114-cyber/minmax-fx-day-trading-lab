## Phase 2: React + Firebase (将来計画)
- **技術スタック案**: React 19 + TypeScript + Vite 7 + Tailwind + Firebase (Auth/Firestore/Functions/Hosting)
- **リファレンス実装**: `C:\Users\Atsushi Hasebe\AppData\Local\Temp\trading-app-v2-inspect` (trading-app-v2 のクローン)
  - Auth: `src/hooks/useAuth.ts` で `ALLOWED_EMAILS = ['hasebe201114@gmail.com']` のホワイトリスト

  - Hosting: asia-northeast1 リージョンで配信
- **想定画面**:

  - 通貨別ページ: 個別バックテスト詳細 + チャート (equity/DD/trade distribution)
  - 戦略管理: SYS-FX007 v2.1 などの戦略バージョン管理、パラメータ変更履歴
  - レポート出力: PDF / Markdown 形式での自動生成
- **移行判断基準**:
  - 限定共有の要望が顕在化 (現状は Hasebe-san 個人用途のみ、優先度低)
  - インタラクティブなパラメータ探索やアラート機能の要望
