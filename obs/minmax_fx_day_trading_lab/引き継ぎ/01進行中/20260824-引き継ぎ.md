## 重要な懸案（次セッションが引っかかりやすい点）

### 1.（解決済み）SYS-FX022のライブ監視自動化は最終的にGitHub Actionsへ集約

3つの自動実行方式を試した経緯（2026-08-24時点）:

| 方式 | 結果 |
|---|---|
| Claude使い捨てセッションRoutine（`create_new_session_on_fire`） | 発火は記録されるがgit pushが完了しない（**原因未特定のまま棚上げ**） |
| GitHub Actions（`.github/workflows/live-ticker-poll.yml`） | 当初は無料枠超過で即時失敗 |
| Firebase Cloud Functions（司令塔提案） | 実装したが、下記の理由で不要になり**削除済み** |

**2026-08-26、司令塔がGitHub Actions無料枠の制約を解消し、`live-ticker-poll.yml`が実際に稼働を開始した**（`github-actions[bot]`名義のコミット`9bc9616`等で確認済み）。Firebase Cloud Functionsは二重運用を避けるため`functions/`・`firebase.json`ごと削除した。

さらに司令塔がこのセッションの外で以下を追加構築済み（2026-08-26、詳細はコミットログ参照）:

- `.github/workflows/update-ds1-forward.yml`（毎時）: M5 OHLCVを取得し`data/curated/ds-1-forward.json`を更新（`live-ticker-poll.yml`はbid/ask気配値のみでM5足は更新しないため、別途必要だった）。`fetch_m5_ohlcv.py`新設、`ds-1-forward.json`は.gitignore対象化
- `.github/workflows/sysfx012-fx-forward-cycle.yml`（週次月曜00:00 UTC）: SYS-FX012週次フォワードテストサイクル自体もGitHub Actionsへ移管（下記「懸案2」のClaude Routine不具合への対応）
- `trading-app-v2`側に`sysfx012-fx-forward-sync.yml`があり、ledgerを公開Web UIへ同期

**次セッションでの確認事項**: `git log --oneline -3 -- data/raw/live-ticker/` と `git log --oneline -3 -- research/method-notes/sysfx012_forward_test_ledger.json` で、直近のコミットが数時間〜1週間以内に収まっているか確認する。収まっていれば自動化は生きている。念のため`.github/workflows/`配下の3ワークフローが最新でGitHub Actions上でも成功しているか(`mcp__github__actions_list`)を見ておくとより確実。

### 2.（背景・経緯として記録）SYS-FX012週次フォワードテストのClaude Routineは信用できなかった

`trig_01XuLkqxjKp9WaigqH5W87Z2`（「SYS-FX012 フォワードテスト週次サイクル」、2026-08-22設定、`scripts/forward_test/weekly_cycle.py`を毎週月曜実行するClaude Routine）は、`list_triggers`で見ると**`last_run.status`が`ROUTINE_RUN_STATUS_SUCCEEDED`（2026-08-24 00:11〜00:13、約2分19秒稼働）と表示される**のに、実際には`sysfx012_forward_test_ledger.json`が2026-08-22 20:43から更新されていなかった。つまり「Routine自体は正常終了と判定されている」のに「実データへの反映が起きていない」という、単純な失敗より診断が難しいパターン。**この不具合が、司令塔が上記のGitHub Actions版（`sysfx012-fx-forward-cycle.yml`）へ移管した動機**。GitHub Actions版と二重に動くと紛らわしいため、本引き継ぎ作成時にこのClaude Routine（`trig_01XuLkqxjKp9WaigqH5W87Z2`）は`enabled=false`へ無効化した（削除はしていない、履歴として残る）。

### 3. mainに軽微な検証用コミットが残っている（実害なし）

コミット`096a21b`（メッセージ「test: スクラッチクローンからのpush検証(すぐrevertされる)」）が`main`に残っている。中身は実際のライブティックデータ4行で無害だが、メッセージが「revertされる」と書きつつ実際にはrevertしていない。実害はないため放置で問題ない（説明のためここに記録）。
