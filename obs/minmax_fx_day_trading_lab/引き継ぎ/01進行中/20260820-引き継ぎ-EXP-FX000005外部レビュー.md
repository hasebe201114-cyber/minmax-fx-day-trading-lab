## 検算で確認された事実

### F1: 週末強制クローズが一度も発動していない

```
train 27/345 (7.8%) / validation 6/104 (5.8%) / test 8/173 (4.6%)
合計 41/622 件（6.6%）が土曜 06:00 JST を跨いで保有、WEEKEND_* 決済は 3 期間とも 0 件
```

`is_weekend_close_time()` が「土曜 06:00 以降の H1 バーの存在」を前提にしているが、
市場が閉まっているのでそのバーは DS-1 に存在せず、条件が一度も真にならない。→ **T-01**

### F2: `permutation_p < 0.05` は 4 通貨構成では原理的に達成不能

```
4通貨・全トレード勝ち（理論上最強のエッジ）: n=100 も n=20,000 も p=0.3158（不変）
参考: 単一通貨・全勝 n=100 なら p=0.000050
```

`permutation_test_clustered()` は通貨ペアごとに符号を 1 個引いて全トレードへ一括適用するため、
検定の実効標本サイズが「通貨ペア数 = 4」になる。**p 値の下限が 0.3158。** → **T-06**

### F3: ATR トレーリングが事実上一度も作動していない

```
TP_THEN_SL_TRAIL 225 件のうち 89.3% が建値ストップの値ちょうど（+0.40 / +1.10）、最大 +1.53
```

`atr_trail_multiplier = 3.23`（SYS-FX009 の H1 設計からの転用）は本戦略の 1R（M5 スケール）に対して
3〜4R 相当で、TP3 = 4R に先に到達するため原理的に噛まない。→ **T-02**

### K3m / n_eff

- 最大連続損失 ≤ 5 は n 依存で、i.i.d. でも通過率 59〜72%。観測値のパーセンタイルは 0.28〜0.72 で
  ランダムと区別がつかない → **T-08**
- `n_eff = 名目n × 0.292` なので `min_n_trades=300` には**名目 1,027 件**が必要。
  「週 1 回の厳選」という戦略コンセプトと定義上両立しない → **T-07**
