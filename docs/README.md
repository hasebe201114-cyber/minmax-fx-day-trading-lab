# ドキュメント配置（A/B/C/D 区分）

親プロジェクト `minmax-trading-pilot` の規約に準拠し、4 区分のドキュメント階層で管理する。

## 区分

| 区分 | 内容 | 命名規則 |
|---|---|---|
| **A-運用ガイドライン** | 戦略運用・本番化の手順、緊急時対応、KPI 管理 | `A001-タイトル.md` |
| **B-トレーダ向け資料** | 戦略の意図、想定エッジ、市場環境、フォワードテスト結果 | `B001-タイトル.md` |
| **C-トレーディング仕様書** | 戦略ロジック詳細、検証仕様、データ仕様 | `C001-タイトル.md` |
| **D-開発者向けシステム仕様** | アーキテクチャ、API 仕様、テスト仕様 | `D001-タイトル.md` |

## 開発者向け（A-000 番台）

開発フローの詳細は `CLAUDE.md` を参照。重要なルール:

- **コードは Python 3.11+ エコシステムで構築**（pandas / numpy / vectorbt / optuna / pandas-ta / structlog）
- **GMO FX API クライアントは親PJから流用**（`src/minmax_fx_dt/data/gmo_fx_client.py`）
- **リスク・判定・通知は親PJの資産を本PJ用に拡張**（K1m〜K7m 7 指標、v2 拡張）
