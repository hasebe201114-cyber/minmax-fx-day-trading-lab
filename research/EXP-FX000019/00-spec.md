## 仮説（1行）

## 2. 配分ウェイト（**Validation を見る前に固定**）

- **等ウェイト 50:50、日次リバランス**
- 根拠: 事前診断（Train）で既にこの配分で測定しており、**結果を見てから配分を変えないため**に固定する。逆ボラティリティ配分等の代替案は本EXPでは検討しない（1変数の原則）
- 各戦略に初期資金 $1,000 の 50%（=$500）を配分したものとみなし、**日次リターンの単純平均**で合成エクイティを構成する

## 3. 評価方法（Validation を見る前に固定）

### 3.1 合成エクイティ

- 各戦略のエクイティカーブを**日次終値**へ揃え（前方補完）、日次リターンを取る
- 合成日次リターン = (戦略Xの日次リターン + 戦略Yの日次リターン) / 2
- 合成エクイティ = 初期$1,000から累積積

### 3.2 合成トレード列（PF・ペイオフ・K5m・permutation test 用）

- 両戦略のトレードを結合し、**各トレードの `dollar_pnl` を 0.5 倍**する（50%配分に対応）
- permutation test のクラスタキーは **ISO年-週**（SYS-FX024 §6.2 と同じ保守側の設計。両戦略のトレードが同一週に共起する依存構造を吸収する）
- `n_trades_effective` は相関割引なし（T-07規約）

## 4. 選定ルール（**Validation を見る前に固定**）

本EXPの主目的は「Train で観測された合成効果が Validation で再現するか」の確認である。**判定は次の3段階で機械的に行う。**

1. **再現した**: Validation で、合成が **(a) 月次シャープが単独最良以上** かつ **(b) 最大DD（ピーク比）が単独最良以下** を**両方**満たす
2. **部分的に再現**: (a)(b) のどちらか一方のみを満たす
3. **再現せず**: どちらも満たさない

そのうえで:

- **「再現した」かつ合成エクイティが必須9項目すべて達成** → ポートフォリオとしての採用候補として司令塔に具申する
- **「再現した」が必須ゲート未達** → 未達項目を明記した上で、改善ループ（上限2回）へ
- **「部分的」または「再現せず」** → **合成効果は Train 固有のアーティファクトだったと判定し、REJECT を具申する**。この場合、ウェイトを変えて再試行することは**しない**（配分の後付け調整は HARKing）

## 6. 想定される失敗モード（Validation を見る前の正直な記録）

1. **Train の負相関がレジーム固有だった可能性。** Train（2023-11〜2025-03）は円安トレンドが支配的な局面であり、グリッドが負けて SYS-FX011 が勝つ関係が固定化していたかもしれない。Validation で相場付きが変われば相関は正に転じうる
2. **戦略Yの期待値が負である以上、相関が弱まると単に足を引っ張る。** 合成リターンは必ず単独Xより低くなる（−1.4%の資産を半分混ぜるため）。改善しうるのはリスク調整後の指標のみ
3. **Validation の日数が約170営業日と短く、DD の推定が不安定。** 最大DD は1回の大きな谷で決まるため、再現性の判定が偶然に左右されやすい
4. **合成しても K4m（ペイオフレシオ ≥ 1.5）は達成できない可能性が高い。** 戦略Xの Validation ペイオフは 1.18、戦略Yは 0.69 であり、混ぜても 1.5 には届かない見込み。**この1項目だけで必須ゲートは未達になる**

> 特に 4 は、**Validation を見る前の時点で「必須9項目すべて達成」はほぼ不可能だと予想している**ことを意味する。それでも本EXPを実施する価値は、「ポートフォリオ評価という枠組みが機能するか」という**方法論の検証**にある。K4m の扱い（SYS-FX024 で PF ベースへ置換した前例がある）は、再現性が確認できた場合に改めて議論する。

## 7. 改善ループの停止条件（Q10、prescreenで事前登録済み）

- 上限 **2回**。本spec（Validation 再現性確認）はベースライン評価でありカウントしない
- 上限到達かつ必須ゲート未達なら自動的に REJECT 確定

### 解釈（正直な記録）

- **本プロジェクトで初めて、Train で観測された効果が Validation で再現した。** 単独戦略の検証では一度も起きなかったことである
- **ただし仮説は「当たったが、当たった理由が想定と違う」。** Validation の相関は **−0.058** と Train の −0.224 から大きく弱まっており、**「構造的な負相関」というメカニズムは再現していない**。Validation で合成が効いたのは、**戦略Y（SYS-FX024 R-A）が Validation では単独で +8.09%・シャープ 1.191 とプラスに転じたため**である
- これは警告でもある。**戦略Y の Train（−3.01%）と Validation（+8.09%）の乖離は大きく、レジーム依存の疑いがある**。「グリッドは常にトレンドで負ける」という単純な描像では説明できない
- **§6 の失敗モード予想 #4（合成してもペイオフ 1.5 には届かない）は的中**した。予想どおりこの項目が最大の障害である
- 最大DD が Validation で **3.60%** まで下がった点は実務的に大きい。単独X の 5.56%、単独Y の 6.33% のいずれよりも低く、K2m（月間 ≤ 10%）を大きな余裕でクリアしている

### 判定

**§4 の3段階判定「再現した」。ただし必須9項目は未達（Validation 7/9）。** §4 の規則に従い、未達項目（ペイオフレシオ・permutation有意性）を明記した上で改善ループ（上限2回）へ進む → `00-spec-amendment-01.md`
