## 仮説（1行）

**同一イベント内の再エントリーをentry_seq≤3に制限すれば、ピラミッディングによる希薄化を避け、正式なKPIパイプラインでペイオフレシオ・統計的有意性が改善するのではないか。**

## 検証範囲

- **対象通貨**: USD_JPY・EUR_JPY・GBP_JPY・AUD_JPY
- **変更する変数**: `max_entry_seq=3`（新規パラメータ、entry_seq>3のエントリーを見送る）
- **完全凍結**: 検出層(H1、N_BREAKOUT=3.5・zigzag閾値=2.0)、`stop_buffer_atr_m5=0.703`、`atr_trail_multiplier_m5=0.703`、`breakeven_trigger_r=1.0`、`tp_levels=[]`、コストモデル、検定方式
- **Train期間のみ**: 2023-11-01〜2025-03-31

## 実装方針

`simulate_dow_theory_trend()`に`max_entry_seq: int | None = None`パラメータを追加する（`skip_first_entry`と同じ実装パターン、既存の`entry_seq`カウンタを流用）。`entry_seq > max_entry_seq`の場合はエントリーせず、ダウ理論のスイング構造追跡自体は継続する。デフォルト`None`は既存挙動と完全に同一（後方互換）。

**判定ルール**:

- **ペイオフレシオが改善しない、または他のKPIが明確に悪化** → 不採用と判定してクローズ

事前登録した`max_entry_seq=3`という単一の値で評価し、結果を見た後に別の値へ変更しない（この点自体がHARKing防止の核心）。

## 結果（2026-08-23実施）・不採用

| 指標 | 候補①(基準) | +max_entry_seq=3 |
|---|---|---|
| 必須KPI達成数 | 7/9 | **5/9**(悪化) |
| 実効n | 300 | 167(悪化) |
| 月次シャープ | 2.397 | 2.154(悪化) |
| ペイオフレシオ | 1.078 | 1.178(改善、ただし1.5未達) |
| Profit Factor | 1.759 | 1.848(改善) |
| 最大DD | 8.69% | 6.43%(改善) |
| スプレッドコスト倍率 | 2.35 | 2.68(改善、ただし3.0未達) |
| permutation_p | 0.031(有意) | **0.0539**(非有意化) |

**結論・不採用**: ペイオフレシオ・PF・DDは改善したが、いずれもK4m/K5m基準には届かず、最も重要な**実効n・permutation_pがむしろ悪化**した(KPI達成数7/9→5/9)。EXP-FX000009の議論で提示した簡易プローブ(複利前の単純Rマルチプル平均、entry_seq≤3でperm_p=0.019)とは異なり、**正式なKPIパイプライン(複利エクイティカーブ+リスクベースサイジング込み)ではperm_p=0.0539とむしろ悪化した**。これは簡易プローブが複利・サイジング効果を無視した粗い近似に過ぎず、正式なパイプラインでの評価が必須であることを裏付ける結果でもある。事前登録した判定ルール「ペイオフレシオが改善しない、または他のKPIが明確に悪化」に該当し、**Train単独で不採用と判定してクローズ**。フォワードテスト中の候補①の設計に変更なし。
