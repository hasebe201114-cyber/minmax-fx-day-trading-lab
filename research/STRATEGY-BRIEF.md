## 1. 戦略ポートフォリオの前提

### 1.1 北極星 KPI

- **月次シャープレシオ** ≥ 0.4（6ヶ月フォワード）
- **月次 Profit Factor** ≥ 1.2
- **月次期待値** > 0 円
- **月間最大 DD** ≤ 10%（年間 ≤ 20%）
- **ペイオフレシオ** ≥ 1.5
- **最大連続損失** ≤ 5 トレード
- **バックテスト ↔ フォワードテスト乖離率** ≤ 30%
- **両建て状態の最大証拠金消費率** ≤ 30%

### 1.2 スコープ

- 対象通貨: **最大 5 通貨**（OBS000002 で選定、暫定案 A: USD/JPY, EUR/JPY, GBP/JPY, AUD/JPY, EUR/USD）
- 時間軸: マルチタイムフレーム
  - LT = D1 / W1（方向）
  - MT = H4 / H1（レンジ）
  - ST = M15 / M5（戻り確認）
- ホールド期間: 数日〜数週間
- 週末持ち越し: 禁止（土曜 06:00 JST までに全決済）

### 1.3 コスト前提

- スプレッド: 通貨ペア別（USD/JPY 0.3 銭、GBP/JPY 0.7 銭 等）
- API 手数料: 0.002%（30日間無料トライアル中は実質ゼロ）
- スリッページ: 0.5 pip 固定フォールバック
- **スワップポイント**: 両建て時にロング・ショート両側で発生、正味で計算
- 両建ての証拠金: 通貨ペア × 想定レバレッジで内部管理、最大 30% に制約
