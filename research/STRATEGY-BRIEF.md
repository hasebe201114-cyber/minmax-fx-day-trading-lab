## 1. 戦略ポートフォリオの前提

### 1.1 北極星 KPI

- **月次シャープレシオ** ≥ 0.4（6ヶ月フォワード）
- **月次 Profit Factor** ≥ 1.2
- **月次期待値** > 0 円
- **月間最大 DD** ≤ 10%（年間 ≤ 20%）
- **ペイオフレシオ** ≥ 1.5
- **最大連続損失** ≤ 5 トレード
- **バックテスト ↔ フォワードテスト乖離率** ≤ 30%
- **両建て状態の最大証拠金消費率** ≤ 30%

### 1.2 スコープ

- 対象通貨: **最大 5 通貨**（OBS000002 で選定、暫定案 A: USD/JPY, EUR/JPY, GBP/JPY, AUD/JPY, EUR/USD）
- 時間軸: マルチタイムフレーム
  - LT = D1 / W1（方向）
  - MT = H4 / H1（レンジ）
  - ST = M15 / M5（戻り確認）
- ホールド期間: 数日〜数週間
- 週末持ち越し: 禁止（土曜 06:00 JST までに全決済）

### 1.3 コスト前提

- スプレッド: 通貨ペア別（USD/JPY 0.3 銭、GBP/JPY 0.7 銭 等）
- API 手数料: 0.002%（30日間無料トライアル中は実質ゼロ）
- スリッページ: 0.5 pip 固定フォールバック
- **スワップポイント**: 両建て時にロング・ショート両側で発生、正味で計算
- 両建ての証拠金: 通貨ペア × 想定レバレッジで内部管理、最大 30% に制約

### 2.1 SYS-FX007（レンジブレイク・プルバック）— REJECT確定の要点

- 3 レイヤ MTF 構造 + 5 条件 AND（LT方向 + MT-1/2/3 + ST戻り確認）で検証
- 実装バグ15件を発見・修正、検証プロセス構造（判定エンジン未接続・停止条件なし）を是正
- パラメータをデータ駆動で再設計（トレンド強度軸: ADX等3指標、SL/TP/Donchian軸: ZigZagベースの期間再設計）してもエッジ検出できず
- 唯一十分なサンプル数（pooled n=125）を確保できたケース（Donchian期間再設計）でも perm_p=0.80 と明確に非有意
- 詳細は `portfolio-ledger.md`・OBS000001, 003〜007 を参照

### 2.2 SYS-FX008（トレンドフォロー・MAクロス）— REJECT確定の要点

- 想定エッジ源: 長期トレンドの継続性。レンジ相場では OFF
- LT(D1) SMAクロス+ADXフィルター、MT(H4)継続確認の2レイヤ構造。MA期間・ADX閾値・トレーリング幅をすべてデータ駆動で導出
- 改善ループ3試行（初期プリセット→E1: トレーリング幅再導出→E2: MT確認期間再導出）すべてTrain選定基準未達で停止条件トリガー
- **SYS-FX007との違い**: プール平均損益が3試行とも一貫して正、最良のE1でUSD/JPY単独perm_p=0.058と有意水準に近く、「エッジは弱いがサンプル不足で検出できていない」可能性がSYS-FX007より高い
- 詳細は `portfolio-ledger.md`・`research/EXP-FX000002/00-spec.md` を参照
