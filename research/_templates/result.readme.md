# 検証結果（Result）の置き場 - 10-result/

> 担当: 実装チーム（quant-researcher）
> 責任: **生データのみ。判断・採否は記載しない**（C 品質チームが独立に再判定するため）。

このフォルダ `10-result/` に以下を保存する：

| ファイル | 内容 |
|---|---|
| `prediction-unit.json` | 予測単位の結果。過学習検証、permutation p 値、有効 n などを含む |
| `pipeline.json` | パイプライン全体の結果。総 PnL・インパクトメトリックス・コスト内訳・ガスコスト等・最大 DD・時間別・レジーム別 |
| `params.json` | 使用した全パラメータ（バージョン管理） |
| `run.log` | 実行ログ。**再実行用の実行コマンドを必ず含める** |

## ルール
- 結果の良し悪しのコメントを残さない。
- spec が要求した出力は**最低限（予測単位＋パイプライン）**を残す。
- インパクトメトリックス・コスト・スリッページを分割して報告する。省略しない。
- 決定的であること（同一コマンドで同じ結果）。
- 実行コマンドは `scripts/` の実装言語・ツールチェーンに合わせ spec で指定する（Python/Node.js など）。
- **`run.log` は 1 検証につき 1 ファイルで、内容に再現に必要な全情報を含める**。git で追跡する
