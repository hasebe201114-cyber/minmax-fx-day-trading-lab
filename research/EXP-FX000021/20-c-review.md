## 1. 決定的な指摘 — 未修正の先読みが3期間すべてとフォワード基盤に載っている

### 指摘内容

`derive_vol_breakout_entry_params.to_h1()` は `resample("1h")` を **label 既定（=left）** で使うため、
**H1インデックスはバーの「始値時刻」**である。一方 `backtest_vol_breakout_dow_theory.py` は

```python
break_time = h1.index[break_idx]                    # = バー始値時刻
start_time = break_time + pd.Timedelta(minutes=30)  # = バー確定の30分「前」
```

としており、**エントリー探索がブレイクH1バーの確定30分前から始まる**。
ブレイク判定自体は `(high − low) / ATR ≥ 3.5` という**バー確定後にしか分からない値**を使うため、
**まだ確定していないバーの高値・安値・終値を使ってエントリーしうる**＝先読みである。

- `00-spec.md` は「ブレイクバー**確定後**30分」と明記しており、**実装が仕様と食い違っている**
- `OBS000009`（2026-08-27起票）が同じことを「不具合1」として記録済み。
  チェックボックスは `[ ]` **未着手**、「司令塔判断待ち」のまま放置されていた
- `01-trade-conditions.md` §3 の「そのH1バーの**次の**M5バーから追跡を開始する」という記述は**誤り**

始値時刻を紐づけて `entry_time − break_time < 60分` を「バー確定前エントリー」と判定した。
**pandas の label 既定が left であることも実証済み**（`resample('1h')` の先頭 index が 00:00）。

### なぜ「単に成績が良く出ていた」で済まないか

- **Train・Validation では先読みを除くと成績が上がる**（Validation は平均r_net 0.869→1.154）。
  つまりこの先読みは一律に成績を水増しするものではなく、**期間によって符号が変わるノイズ**である
- **だからこそ危険**である。実運用では**どちらの方向であれ再現できない**。
  バー確定前に「そのバーが3.5×ATRのブレイクになる」ことは原理的に知り得ない
- Test では純損益の **37.4%** がこの実行不可能なトレードから出ている

フォワード基盤（`run_forward_test_cycle.py`）は**同じ `simulate_dow_theory_trend()` を呼ぶ**ため、
**このまま走らせても先読みを含む数字が積み上がるだけ**である。
さらに `amendment-03` §2 は「フォワード期間の成績を見てパラメータを変更する場合、
それまでのフォワード実績は無効として捨てる」と宣言済みであり、
**後から直せば蓄積を捨てることになる。**

## 2. その他の重大な指摘（査読者による、B側で未検算のものは「未検算」と明記）

OBS000009 不具合2（「成功と記録されるのに実データが更新されない」）と同じ死角である。

**sysfx026 分岐は正常動作すると確認**（53トレード生成、mean_r_net 0.5915、K5m 2.59、必須7/9）。
**動作すること自体は確認されたが、それを確認したのはB側ではない。**
恒常的なスモークテストの不在は差し戻し事項。

副産物: 2.9ヶ月で53件＝**月18件**。amendment-03 §4 の「月14件・n=300到達は約21ヶ月」は保守的
（月18件なら約17ヶ月）。

### 2-2. Q15（n の期間考慮）と amendment-03 が相互に矛盾（**妥当と認める**）

- `min_n_trades_for_window(m) = round(300 × m / 16.95)` は実質「**月17.7件の頻度要求**」であり、
  **窓が伸びれば閾値も同率で伸びるため時間を積んでも収束しない**
- amendment-03 §4 は「21ヶ月で n=300 に到達」という**絶対値への積み増し**を前提にしており両立しない
- **`min_n_trades_for_window` はどこからも呼ばれていない**（定義のみ、テストなし）。
  `evaluate_period()` は依然 300 固定。Q15 は文書上のルールに留まっている
- HARKing 該当性について査読者は「**グレーだが、フォワードのデータが貯まる前に適用可否を
  確定すれば無害化できる。貯まってから決めるのは明確に HARKing**」と評価。この評価に同意する

### 2-3. K5m の「基準3.0が振れ幅の中央」という読みは先読みに支えられていた

先読み除外後: **3.812 / 6.707 / 2.085**。3期間平均はほぼ変わらないが、
**唯一のホールドアウトである Test だけが基準からさらに遠ざかる。**
