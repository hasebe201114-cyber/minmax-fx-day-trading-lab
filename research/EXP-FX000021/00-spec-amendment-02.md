## 1. 経緯と、司令塔判断による手順の変更

amendment-01 §8 で S 戦略チームは **(3) C品質チームの独立査読 → (1) Test 1回参照** の順を
推奨したが、**司令塔判断は「1のあと2へ」（①Test → ②フォワード投入）**であり、
**C査読（3）は実施せずに Test へ進む**こととなった。

これに伴い、amendment-01 §7 で新たに記録した **通貨集中（AUD/JPY 偏重・GBP/JPY が
Validation でマイナス）は、独立査読を経ないまま残る**。この点は本amendmentの結論に
必ず併記する。

## 4. 判定ルール（**Test を見る前に固定**）

実効n は Test 期間（2025-12-01〜2026-08-15、約8.5ヶ月）でも 300 に到達しないと
**事前に予想される**（amendment-01 §7 の構造的制約と同じ理由）。したがって
「9/9 か否か」を主判定にすると、結果によらず自動的に不合格となり情報を得られない。

そこで、**サイジングで動かせない指標と構造的指標に絞った次の4条件**を主判定とする
（実効n は別途 **必ず実測値を記録**し、未達なら未達として明記する）:

> **主判定4条件**: ①平均 r_net > 0 ②K4m ペイオフ ≥1.5 ③**K5m コスト倍率 ≥3.0**
> ④**permutation p（日ブロック） <0.05**

| 分類 | 条件 | 次のアクション |
|---|---|---|
| **A: 再現した** | 主判定4条件を**すべて**満たす | Train・Validation・Test の3期間すべてで再現。**②フォワードテスト投入へ進み**、実効nを本物の未見データで積む段階に移る |
| **B: 部分的に再現** | 4条件のうち**1つ**が未達 | 否定はされないが確証も得られない。②フォワード投入は行うが、**採用GOは具申しない** |
| **C: 再現しなかった** | 4条件のうち**2つ以上**が未達、または**平均 r_net が負** | Train/Validation の結果は Test 期間へ一般化しない。**SYS-FX026 の採用は具申せず**、司令塔へ REJECT を含む選択肢を提示する |

**あわせて通貨別内訳・1通貨除外感度も同時に測定し（amendment-01 §7 と同一手順）、
結果に必ず併記する。** C査読が行われないため、この機械的チェックが唯一の
通貨集中に対する検証となる。

## 5. 一度限りの原則（**最重要、Test を見る前に宣言**）

**本 Test 参照は一度限りである。**

- **Test の結果を見た後に、パラメータ・通貨構成・出口設計・サイジングを変更して
  再び Test を引くことを、いかなる理由でも行わない。**
- 分類 C（再現せず）となった場合、**「Test に合うように直す」ことはしない。**
  設計を変更したい場合は新規 EXP 番号を起票し、**その戦略にとって Test はもはや
  ホールドアウトではない**（既に消費済み）ことを明記した上で、判断材料としての
  重みを下げて扱う。
- EXP-FX000005 T-05 の凍結宣言は、本参照をもって **SYS-FX011 系列について消費される**。

## 6. 既知の留保（**Test を見る前に記録、結果の解釈を左右する**）

**Test は SYS-FX026 にとって「半分だけ清潔な」ホールドアウトである。** 正直に切り分ける:

| 対象 | Test は清潔か | 理由 |
|---|---|---|
| **トレール幅3.0倍・risk_pct 0.65%**（SYS-FX026 の変更点） | **✅ 完全に清潔** | いずれも Train 単独から導出し、Test は一度も参照していない |
| **基盤設計**（N_BREAKOUT・stop_buffer・ダウ理論エントリー・ショック抑制フィルター・4通貨選定） | **❌ 清潔ではない** | SYS-FX011 の改善ループ第1〜7試行で **Test が14回以上参照された後**に T-05 で凍結された。基盤設計はその過程で形作られている |

したがって **Test で良い結果が出ても、それは「基盤設計が Test に適合していること」の
再確認を含んでおり、純粋な out-of-sample の証拠としては割り引いて読む必要がある。**
逆に **Test で悪い結果が出た場合は、その否定的な意味は割り引く必要がなく強い**
（適合させたはずの期間ですら再現しないことになるため）。

## 7. 想定される失敗モード（Test を見る前の正直な記録）

1. **実効n は 300 に届かない見込み**（約8.5ヶ月、Validation の91 と同程度〜やや多い程度）。
   これは事前予想であり、未達をもって戦略の欠陥とは扱わない（ただしゲートは動かさない）
2. **GBP/JPY が Test でもマイナスの可能性が高い。** Validation で −0.218 だったものが
   反転する積極的な理由はない
3. **AUD/JPY 偏重が Test では再現しない可能性がある。** Validation の AUD/JPY 突出
   （平均r_net +1.965、n=30）は小標本であり、Test で平凡化すれば全体の水準は下がる
4. **Test 期間（2025-12〜2026-08）は Train/Validation と相場環境が異なる可能性がある。**
   レジーム依存があれば露呈する。これは**露呈することが望ましい**

### 最重要の所見: K5m は Test で基準を割った

**SYS-FX026 は K5m（コスト倍率）という壁を壊すために作った戦略であり、その当の指標が
ホールドアウトで基準を割った。** これが本参照の中心的な結果である。

**ただし、変更そのものは out-of-sample で確かに効いている。** 同一の Test 期間で、
SYS-FX026 が改変した直前身（SYS-FX011 v7 trailonly、`vol_breakout_dow_theory_4pairs_v7_trailonly_kpi_evaluation.json`、
凍結前に算出済みの記録値）と比べる:

| 同一Test期間での比較 | 直前身 SYS-FX011 v7 trailonly | **SYS-FX026** |
|---|---|---|
| K5m コスト倍率 | 1.95 | **2.56** |
| K4m ペイオフ | 1.134 | **1.965** |
| 必須ゲート達成 | 4/9 | **7/9** |

**トレール幅3.0倍という変更は、Test を一度も見ずに Train だけから決めたにもかかわらず、
Test でも3期間すべてで一貫して改善をもたらした。** これは変更の有効性に関する
純粋な out-of-sample の証拠であり、amendment-02 §6 の切り分けでいう
「**✅ 完全に清潔**」な部分にあたる。**しかし改善幅は K5m=3.0 を越えるには足りなかった。**

**K5m は期間による振れが大きい**（SYS-FX026: 3.95 / 5.49 / **2.56**、直前身: 2.28 / 3.12 / 1.95）。
基準3.0はこの振れ幅のほぼ中央に位置しており、**「Train と Validation で越えたが Test で
割った」のは、エッジが消えたというより K5m が基準線付近で揺れていると読むのが素直**である。
とはいえ、**基準を割った事実は割り引かない**（§6 の宣言どおり）。

### 通貨別内訳と、C査読が指摘した弱点の再評価

| GBP/JPY | 26 | **+0.404** | 2.145 | 2.502 | 2.397 |

**§7 で結果を見る前に立てた予想のうち、1つが的中し1つが外れた。正直に記録する:**

- **予想#3「AUD/JPY 偏重は Test では再現しない」→ 的中。** Validation で +1.965 と
  突出していた AUD/JPY は Test で +0.494 と平凡化した
- **予想#2「GBP/JPY は Test でもマイナスの可能性が高い」→ 外れ。** Validation で
  −0.218 だった GBP/JPY は Test で **+0.404 とプラスに転じた**

**この2つを合わせると重要な示唆が得られる: 「どの通貨が弱いか」は期間ごとに入れ替わる。**
Validation では GBP/JPY が負・AUD/JPY が突出、Test では EUR/JPY が負・AUD/JPY が平凡。
**C査読が SYS-FX011 について指摘した「GBP/JPY の薄いエッジ」「EUR/JPY の極小サンプル依存」は、
構造的な弱点ではなく期間固有のノイズだった可能性が高い。** これは C査読の指摘を
否定するものではなく、**小標本（各通貨 n=18〜47）では通貨別内訳から構造を読み取ること
自体が難しい**という、より根本的な制約を示している。

**1通貨除外感度: K5m は4通り全てで基準未達**（2.12〜2.81）。**K5m の未達は特定通貨の
せいではなく、Test 期間全体に及ぶ系統的なもの**である。単独で3.0を越えたのは
USD/JPY（3.115）のみ。

## 10. 判定と次のアクション

**Test 判定 B（部分的に再現、未達=K5m）。事前登録どおり採用GOは具申せず、
②フォワードテスト投入へ進む。**

3期間を通した SYS-FX026 の位置づけを正直にまとめる:

**確かなこと**
- **トレール幅3.0倍という変更は、Train のみから決めたにもかかわらず3期間すべてで
  一貫して改善をもたらした**（同一Test期間で直前身比 4/9→7/9、K5m 1.95→2.56、
  ペイオフ 1.134→1.965）。本PJが20戦略超で見つけられなかった、**out-of-sample で
  検証された実質的な改善**である
- **K4m（ペイオフ）は3期間すべてで基準クリア**（2.348 / 2.982 / 1.965）。SYS-FX011 が
  一度も越えられなかった壁を、3期間とも越えた
- **permutation p は3期間すべて有意**（0.005 / 0.027 / 0.044）

**確かでないこと**
- **K5m は Test で基準を割った（2.56 < 3.0）。** 期間による振れが大きく、基準線が
  振れ幅の中央にある
- **実効n は Validation・Test とも未達**（91 / 121）。8ヶ月級の窓では構造的に到達不能
- **通貨別の弱点は期間ごとに入れ替わり、小標本では構造を読み取れない**

**したがって次に必要なのは、新しいパラメータではなく新しいデータである。**
フォワードテスト（②）は、実効nを本物の未見データで積み増し、K5m が基準線の
どちら側に落ち着くのかを、ゲートを一切緩めずに判定できる唯一の手段である。
