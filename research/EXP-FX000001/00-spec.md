## 対応 OBS 番号
OBS000001 v2（レンジブレイク・プルバック戦略）

## 紐づく戦略系統 ID

## 仮説（1 行）

5 通貨ペア × 3 レイヤ MTF（LT=D1/W1 方向 / MT=H4/H1 レンジ+ブレイク強度 / ST=M15/M5 戻り確認）の組み合わせで、長期方向一致 + 中期レンジブレイク（Donchian/BB + S/R ラインの 2 サブ条件 (v2.1 で MT-3 を恒久フォールバック)）+ 短期戻り確認の合計 **4 条件 AND** でエントリーし、レンジ内では両建てで刈り取る戦略は、5 年バックテストで月次シャープ ≥ 0.4・月間 DD ≤ 10%・PF ≥ 1.2 を達成できる。

## 採用 / 不採用の数値基準（試算前に確定）

### 採用条件（全て満たすこと）
- **月次シャープレシオ** ≥ 0.4（5 年平均）
- **月次 Profit Factor** ≥ 1.2
- **月次期待値** > 0 円
- **月間最大 DD** ≤ 10%
- **年間最大 DD** ≤ 20%
- **ペイオフレシオ** ≥ 1.5
- **最大連続損失** ≤ 5 トレード
- **両建て状態の最大証拠金消費率** ≤ 30%
- **バックテスト ↔ フォワードテスト乖離率** ≤ 30%
- **permutation p 値** < 0.05
- **有効サンプル数** ≥ 60 トレード（5 通貨 × 5 年 × 3-4 シグナル/年、MT 強化で減少）
- **弱いブレイクの排除率** ≥ 30%（v2 拡張で追加）

### 不採用条件（1 つでも該当）
- 上記採用条件のいずれかを満たさない
- 確認不足で再現不能（HARKing 疑い）
- false breakout 比率 > 50%（4 条件 AND の意義が失われる、v2.1 で MT-3 恒久フォールバック化により 5→4 条件）
- 通貨ペアの 60% 以上で PF < 1.0（汎用性の欠如）
- MT-2 (S/R ライン) が常に満たせない（= データが機能していない、v2.1 で MT-3 は恒久フォールバック済みのため本条件からは除外）

### フォワードテストの追加条件
- 30/60/90 日の各チェックポイントで採用条件を維持
- 月次で KPI を計測、3 ヶ月連続未達で C 品質チームが保留判定

## 採用 / 確認プロトコル（過学習検証付き）

- **Train（学習）データ**: 2020-01 〜 2022-12（3 年、レンジ安定 + コロナショック + インフレ初期）
- **Validation（検証）データ**: 2023-01 〜 2024-06（1.5 年、利上げサイクル + 日銀緩和継続）
- **Test（最終テスト）データ**: 2024-07 〜 2025-12（1.5 年、日銀利上げ + 高ボラ）
- **両者を再学習しない**（train → validation → test の順で 1 度だけ評価）

## 検証範囲

- **通貨ペア**: USD/JPY, EUR/JPY, GBP/JPY, AUD/JPY, EUR/USD（OBS000002 案 A）
- **時間軸階層**:
  - LT = D1 / W1（MA(50) / MA(200) / ADX(14)）
  - MT = H4 / H1（Donchian(20) / BB(20,2) / ATR(14) + **S/R ライン（DS-1 派生）+ 注文板/センチメント（DS-8、v2.1 で現状未使用、DS-8 利用可能時に拡張）**）
  - ST = M15 / M5（ピンバー / 包み線 / ストキャス RSI ダイバージェンス）
- **ホールド時間制約**: 最低 4 時間（土曜 06:00 JST までの持ち越し禁止、Q7 厳守）
- **コスト前提**:
  - スプレッド: 通貨ペア別（USD/JPY 0.3 銭、EUR/JPY 0.5 銭、GBP/JPY 0.7 銭、AUD/JPY 0.6 銭、EUR/USD 0.3 pip）
  - API 手数料: 0.002%
  - スリッページ: 0.5 pip
  - スワップポイント: 両建て時に正味計算（DS-7）
- **両建て制約**: 同時両建てポジション最大 5 セット、証拠金消費率 ≤ 30%
- **経済指標制約**: DS-3 の ±30 分は新規エントリー禁止
- **通貨相関制約**: 相関 ≥ 0.8 のペアは同時エントリーしない

- **重み付け判定**: v2.1 で MT-3 を恒久フォールバック化、MT-1 必須、MT-2 (S/R ライン) 必須の **2 サブ条件 AND** に確定（旧 MT-1/MT-2/MT-3 の 3 サブ条件は解消、DS-8 利用可能時に MT-3 再有効化で 3 サブ条件復帰）

## 使用スクリプト / 再現方法（予定）

- 新規/利用スクリプト: `scripts/exp/exp-fx000001.ts`

- 結果は `10-result/prediction-unit.json`, `pipeline.json`, `params.json`, `run.log` に出力

## 想定エッジケース対応（OBS000001 §7 から転記）

| # | 懸念 | 対応 |
|---|---|---|
| C1 | レンジが小さすぎ | MT レイヤで最低レンジ幅 = 1 ATR 以上を制約に追加 |
| C2 | レンジが長大化 | 両建ての最大保有期間 = 20 営業日 / 含み損 = 証拠金の 5% で強制解消 |
| C3 | 経済指標急変 | DS-3 で経済指標 ±30 分のエントリー禁止 |
| C4 | 長期方向の判定遅れ | LT レイヤの MA(50)/MA(200) クロスで両建て強制解消 |
| C5 | 通貨間の相関が高すぎ | 相関 ≥ 0.8 のペアは同時エントリーしない |
| **C6** | **GMO リテール FX で注文板深度データなし** | **v2.1: DS-8 が利用可能になるまで MT-3 を恒久的にフォールバック (passes=True) = 4 条件 AND で確定**。GMO で取得可能になった段階で MT-3 を再有効化 |
| **C7** | **S/R ラインの過剰検出** | 直近 1 年 3 回以上テスト + ATR 0.5% 以内の接触のみ主要 S/R と認定 |
| **C8** | **MT-3 が常に満たせない** | **v2.1: MT-3 を恒久的に条件から除外し、4 条件 AND 確定で解消**。旧 C8 の「MT-3 を満たさずとも MT-1 + MT-2 + 残り 4 条件でエントリー可 (重み付け判定)」は廃止 |
